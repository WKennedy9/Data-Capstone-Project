# Data-Capstone-Project
Senior Data Capstone 2026
My senior project used 15 years of baseball data, excluding fielding, to calculate WAR for hitters and pitchers. In the New Jersey Athletic Conference, NJAC, player and pitcher of the year are voted on by the coaches. I believe that there is bias in the voting and performance is not the sole qualification. In this project I used the following models: Logistic Regression, Random Forest, and SVM.
